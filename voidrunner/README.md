# VOIDRUNNER - Versión Simplificada

Un juego 3D espacial minimalista hecho con JavaScript, HTML, CSS y Three.js.

## 🎮 Características

- **Nave única** con diseño simple
- **Suelo visible** con grid para referencia visual
- **Jugabilidad fácil** al principio
- **Controles simples**: WASD o flechas
- **Sistema de puntuación** con récord guardado
- **Ajustes de volumen**
- **Solo 326 líneas de código** JavaScript

## 🎯 Cómo Jugar

1. **JUGAR**: Inicia el juego
2. **WASD/Flechas**: Mueve la nave
3. **Esquiva**: Los obstáculos rojos
4. **P/ESC**: Pausa el juego
5. **Sobrevive**: El mayor tiempo posible

## 🚀 Instalación y Ejecución

```bash
cd voidrunner
npm install
npm run dev        # Desarrollo
npm run build      # Producción
```
